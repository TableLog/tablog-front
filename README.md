## Git Convention
### Branch
- common, login, recipe-page, main, …
- 페이지 or 작업 단위

### Commit
| prefix | 의미 |
|:---:|:---:|
| feat | 새로운 기능 추가 |
| fix | 버그 수정 |
| style | ui 및 스타일 관련 |
| test | 테스트 코드 관련 |
| refactor | 코드 리팩토링 |
| revert | 커밋 롤백 |
| chore | 그 외 모든것 (의존성 추가, 빌드 관련 등) |

ex) `feat: 기능 추가`
